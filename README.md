Repository-analysis platform that builds a Neo4j-based code knowledge graph to automatically generate architecture diagrams and learning paths for a codebase. Asynchronous job processing via Celery and Redis for scalable, non-blocking analysis. Backend built with FastAPI, containerized with Docker.
`Python` `FastAPI` `Neo4j` `Docker` `Celery` `Redis`

### [Project Zenith](https://zenith-the-celestial-eye.netlify.app/zenith)
*Jun 2026 · Aerospace / Data Visualization (Hackathon)*
Full-stack real-time space intelligence platform tracking 8,000+ live satellites, the ISS, and all planets from any point on Earth, powered by a deterministic 8-step data pipeline. Implemented SGP4/SDP4 orbital propagation and a visibility engine with geographic pre-filtering that cuts roughly 65% of computation before look-angle calculations. Streams a Gemini-powered AI assistant in real time via Server-Sent Events, with graceful fallback to static responses. Rendering optimized across three synchronized 3D/canvas views using IntersectionObserver-gated animation loops.
`Next.js` `React` `TypeScript` `Three.js` `CesiumJS` `REST APIs`

### AbhayaRaksha
*Parametric Income Insurance for Gig Workers*
ML-driven insurance engine that trains a GradientBoostingClassifier on live weather features (rain, AQI, temperature, time, season) to predict trigger probability, powering a personalized premium engine calibrated across 6 Indian cities. Includes GPS-based fraud detection using an Isolation Forest anomaly model that auto-rejects high-risk claims and flags edge cases for review. Zero-touch payout pipeline built with APScheduler weather polling and the Razorpay Orders API, enforcing actuarial payout caps and moral-hazard limits.
`Python` `FastAPI` `SQLAlchemy` `scikit-learn` `React` `JWT`
